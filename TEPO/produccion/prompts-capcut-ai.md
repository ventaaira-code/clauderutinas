# TEPO — Prompts para CapCut AI
## Estilo visual oficial: CGI fotorrealista

El estilo de referencia ya está definido — ver:
`/personaje/referencias/tepo-estilo-referencia-capcut-ai.mp4`

TEPO es un muñeco bebé CGI fotorrealista con:
- Cabeza pelona, ojos azules expresivos
- Mejillas rosadas, boca pequeña
- Cuerpo regordete de bebé
- Ropa: camiseta blanca/gris con bordes rosas + shorts blancos
- Piel con textura semi-plástica pero con iluminación realista (subsurface scattering)
- Se mueve solo — camina, reacciona, voltea la cabeza

---

## CÓMO USAR CapCut AI para generar a TEPO

1. Abre CapCut en el celular
2. Ve a **IA → Generación de video** (o "AI Video")
3. Selecciona **Text to Video**
4. Copia y pega el prompt
5. Genera — si no te gusta, regenera con el mismo prompt (cada resultado es diferente)

## CONSEJOS PARA MEJORES RESULTADOS EN CapCut AI

| Problema | Solución |
|----------|----------|
| TEPO no parece el mismo en cada video | Usa siempre la misma descripción base al inicio del prompt |
| Video muy corto | Pide duración de 5 segundos en la configuración |
| No tiene movimiento | Añade al final: "camera slowly moves, character moves naturally" |
| Muy oscuro | Añade: "well-lit scene, dramatic but visible lighting" |
| Se ve muy animado, no realista | Añade: "photorealistic, not cartoon, subsurface skin scattering" |
| TEPO no tiene ropa | Añade la descripción completa de ropa en el prompt |
