# TEPO — El Pelón Loquillo
### Serie animada para redes sociales

---

## Resumen del proyecto

Serie de videos cortos protagonizada por **TEPO**, un muñeco de plástico pelón con ojos azules que cobra vida de manera accidental y termina viviendo aventuras en el mundo real entre humanos.

**Tono:** Suspenso + comedia (referencia: Chucky CP2 pero con humor)  
**Plataformas:** TikTok, YouTube Shorts, Instagram Reels  
**Objetivo:** Monetización

---
